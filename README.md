# genesys-intern-assignment

## Description
This project is a solution to the Genesys internship assignment.  
The task is to generate all possible letter combinations for a given string of digits (2-9), as on a telephone keypad.  
The solution uses a class-based approach (`Solution`) with a `combinations` method and includes unit tests to ensure correctness.

## Features
- Converts a string of digits (2-9) to all possible letter combinations.
- Ignores digits not mapping to letters (1 is not allowed).
- Limits input length to 4 digits (as per assignment constraints).
- Includes unit tests covering main cases, including empty input.
